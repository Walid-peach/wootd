# Contributing

For local setup, prerequisites, and how to run the stack, see the
[Local Development](README.md#-local-development) section of the README.

## Workflow

1. Open an issue for anything non-trivial before starting work.
2. Branch off `main`, keep PRs focused.
3. Run `make lint` and `make test` before pushing — CI enforces both.
4. Fill out the pull request template.

## Commit style

Use the imperative mood in the subject line (`add city seed`, not `added`).
Keep the subject under 72 characters.
